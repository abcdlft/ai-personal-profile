# 个人知识库（中文）· AI 个人档案仓库

> 英文标识：ai-personal-profile
> 一句话：一处维护，处处可用——让任何支持 GitHub 的 AI 都能读到「我是谁、我喜欢怎么沟通、我忌讳什么」。

这是一个**跨 AI、跨设备共享的个人档案仓库（中文版）**。把你的身份、目标、偏好、禁忌、常用风格和知识沉淀集中放在这里，任何 AI 助手只要把这个仓库当作项目打开，就能按你的方式工作，而不用每次重新解释一遍。

---

## 一、项目说明（项目说明）

| 文件 | 中文名 | 作用 |
|---|---|---|
| `README.md` | 项目说明 | 仓库介绍、使用方法、跨 AI/跨设备指南 |
| `PROFILE.md` | 个人档案 | 身份、目标、偏好、禁忌、常用风格、联系方式（**每次协作优先读它**） |
| `KNOWLEDGE.md` | 知识库 | 经验、决策记录、常用链接、可复用模板（**持续追加**） |
| `WORKFLOW.md` | 协作规则 | AI 读写规则、回退方式、隐私边界 |
| `.github/workflows/sync.yml` | 自动同步 | 每次变更自动校验并提交档案摘要 |
| `.gitignore` | 忽略清单 | 排除敏感文件、大文件、临时文件 |

设计原则：
1. **纯文本、纯 Markdown**——任何 AI、任何编辑器都能读。
2. **模板为主，不填真实隐私**——身份证、密钥、密码一律不入库（详见 `WORKFLOW.md` 的隐私节）。
3. **Git 即版本历史**——每次改动都有 commit，误改可一键回退。

---

## 二、使用方法（使用方法）

### 首次使用（首次使用）
1. 把本仓库克隆到本机：
   ```bash
   git clone https://github.com/<你的用户名>/ai-personal-profile.git
   cd ai-personal-profile
   ```
2. 打开 `PROFILE.md`，按提示填写你的真实情况（**敏感信息留空或只写占位符**）。
3. 打开 `KNOWLEDGE.md`，把已有的经验、决策、链接逐步搬进来。
4. 提交并推送：
   ```bash
   git add .
   git commit -m "中文：初始化个人档案与知识库"
   git push
   ```

### 日常使用（日常使用）
- 想让某个 AI 了解你：让它先读 `PROFILE.md` 和 `KNOWLEDGE.md`。
- 协作完成后：把新经验/新偏好追加到 `KNOWLEDGE.md`，再 `git add / commit / push`。
- 规则细则见 `WORKFLOW.md`。

## 三、跨 AI 共享指南（跨 AI 共享指南）

任何支持 GitHub 的 AI（如各类编码助手、对话助手、Agent）都可以这样接入：

1. **作为项目打开**：把仓库 clone 下来，或用 AI 的「导入仓库 / 打开项目」功能指向本仓库。
2. **给 AI 一条指令**（中文即可）：
   > 请先阅读本仓库的 PROFILE.md 和 KNOWLEDGE.md，之后按我的档案里的风格、格式和禁忌来回答和执行任务；每次任务结束后把新经验追加到 KNOWLEDGE.md。
3. **AI 自动按你的风格输出**：语气、详略、是否用表格/代码块，都从 `PROFILE.md` 的「输出偏好」读取。
4. **新工具接入**：重复第 1~2 步即可，不需要重新描述你的习惯。

支持的场景：对话助手、编码 Agent、自动化脚本、CI 里的 AI review 等。

## 四、跨设备同步指南（跨设备同步指南）

| 场景 | 命令 | 中文说明 |
|---|---|---|
| 换电脑 | `git clone <仓库地址>` | 一键拉全档案 |
| 开始工作前 | `git pull` | 拉取其他设备的最新改动 |
| 结束工作后 | `git add . && git commit -m "中文：更新档案" && git push` | 推送本机改动 |
| 看历史 | `git log --oneline` | 查看每次中文 commit |
| 回退误改 | `git checkout HEAD~1 -- PROFILE.md` | 把某文件回退到上一版 |

建议：每天开工 `git pull`，收工 `git push`；多设备同时改时先 pull 再 push，避免冲突。

## 五、安全提醒（安全提醒）

- 仓库设为**公开**，因此 `PROFILE.md` 里只放可以公开的信息；联系方式建议用占位符或公开邮箱。
- 身份证号、银行账号、API 密钥、密码**绝不入库**；如需记录，只放本地加密文件，并在 `.gitignore` 里排除。
- GitHub Actions 只做本地校验和档案摘要同步，**不对外发送任何数据**。
- 若希望完全私密，建仓时选择 **Private** 即可，文件内容无需改动。
